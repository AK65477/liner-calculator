# 라이너 계산기

안드로이드 브라우저에서 사용하는 리버스 얼라이먼트 계산기입니다. 높이(라이너)와 좌우 이동량을 계산하고, 회전수별 일반 허용값으로 정렬 상태를 판정합니다. **현장 검증 전 시험용**이며, 실제 작업 결과와의 대조가 필요합니다.

## 사용

첫 화면은 작업 메뉴(현재는 「축정렬 · 라이너」만). 완성된 도구만 메뉴에 올림.

새 측정 → 배치와 부호 확인 → 거리 A/B/C → 회전 90/180/270°의 두 게이지 값(90°에서 처음 위 게이지의 좌우 위치 선택) → 결과(높이·좌우·판정).

- 큰 글씨, 64px 이상 버튼, 부호 선택, mm/0.01mm 눈금 칸 수 입력
- 기기 내 자동 저장(`store.js`, 키 `field-app-v2`): 설비 → 작업 → 측정 회차. 회차마다 입력값과 결과 스냅샷, 계산 버전을 보존
- 「새 측정」은 새 작업으로 빈 칸에서 시작(다른 설비에 이전 거리·처짐값이 넘어가지 않게). 「같은 설비 재측정」은 다음 회차를 만들고 거리·처짐·회전수를 이어받으며 이전 회차는 남김
- 「지난 기록」에서 회차별 결과 비교, 설비 이름(선택) 입력
- 예전 저장(`liner-calculator-v1`)은 처음 열 때 1차 측정으로 자동 이전. 예전 키는 지우지 않음. 읽을 수 없는 기록은 덮어쓰지 않고 다른 키로 보관
- 연습 데이터는 실제 저장 기록과 분리
- 게이지 합계 불일치 시 계산 결과를 숨김
- 설치·로그인·외부 라이브러리·분석 추적 없음
- 오프라인 실행(`sw.js`, `manifest.webmanifest`): 처음 열 때 앱 파일을 폰에 저장, 이후 인터넷 없이 실행. 홈 화면에 추가 가능
- 새 버전은 백그라운드로 받아 두고 처음 화면의 「지금 업데이트」로만 적용(측정 중 화면 교체 없음)
- 기록 백업: 「기록 백업 · 불러오기」에서 텍스트(.txt, 내용은 JSON) 파일로 휴대폰에 저장, 불러오기는 없는 기록만 추가(기존 기록 삭제·덮어쓰기 없음)
- 공개 소스에 사용자 사진이나 실제 설비 측정값은 포함하지 않음

## 배치와 계산

모터측 지지대의 U 게이지는 처음 위에서 고정측 허브를 측정합니다. 고정측 지지대의 L 게이지는 처음 아래에서 모터측 허브를 측정합니다. 측정봉이 눌리면 양수이고, 두 축을 함께 회전시킵니다. 게이지 접촉은 바깥둘레의 반경 방향입니다.

S=(U180−sU)/2, M=(L180−sL)/2, k=(M−S)/A.
앞발 증감=−(M+kB), 뒷발 증감=−(M+k(B+C)). 양수는 추가, 음수는 제거.

좌우(모터 뒤에서 고정측을 바라본 방향): 90°에서 U가 오른쪽이면 d=+1, 왼쪽이면 d=−1.
Sx=d(U270−U90)/2, Mx=d(L270−L90)/2, kx=(Mx−Sx)/A. 앞발 이동=−(Mx+kxB), 뒷발 이동=−(Mx+kx(B+C)). 양수는 오른쪽, 음수는 왼쪽.

판정: 두 침 가운데 지점의 평행 |(S+M)/2|와 각도 |k×100| mm/100mm를 Fixturlaser 설명서 허용값 표(213쪽)와 비교. 제조사 기준이 우선.

처짐값은 각 게이지의 실제 시작 위치부터 반 바퀴까지 별도 강체 시험에서 얻은 부호 있는 차이입니다. 상하 게이지의 처짐 부호가 다를 수 있습니다. 미보정은 명시하고, 이미 보정된 입력은 이중 보정하지 않습니다.

열팽창 목표는 0입니다. 개별 발 들뜸(소프트풋)은 범위 밖입니다. 상세 설명과 기술 출처는 `method.html`에 있습니다.

## 검증 및 개발

Node.js 22 이상, Python 3으로 다음을 실행합니다.

```text
npm test
npm run check
python -m http.server 4173 --bind 127.0.0.1
```

수학 테스트는 게이지를 실제로 돌리는 2차원 기하 모의계산(상하·좌우, 회전 방향 양쪽), 독립적인 축 높이 전진 모델, 평행/각도/반대 방향 보정, 부호 있는 처짐, SKF 수치 사례, 입력 오류를 포함합니다. 0.020 mm 합계 검사 기준은 설비 정렬 허용오차가 아닙니다.

## 배포

파일을 고친 뒤에는 `index.html`, `method.html`, `app.js`, `sw.js`(FILES 목록) 안의 `?v=숫자`와 `sw.js`의 `VERSION`을 함께 한 단계 올립니다. `sw.js`가 바뀌어야 휴대폰이 새 버전을 받습니다. 새 파일을 추가하면 `sw.js` FILES에도 넣습니다.

GitHub Pages: main 브랜치의 루트에서 게시합니다. 별도 빌드가 필요 없는 정적 사이트이며 모든 앱 자원은 상대경로입니다. 소스와 페이지는 공개됩니다.

선택적 WebMCP 읽기 도구는 지원하는 브라우저에서만 등록됩니다. 사용자 조작 없이 측정값을 바꾸지 않습니다.

문자 인코딩: UTF-8, BOM 없음. 확인 문자열: 한글 안전.
