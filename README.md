# 라이너 계산기

안드로이드 브라우저에서 사용하는 리버스 얼라이먼트 수직 라이너 계산기입니다. **현장 검증 전 시험용**이며, 실제 작업 결과와의 대조가 필요합니다.

## 사용

새로 측정 → 배치와 부호 확인 → 거리 A/B/C → 회전 90/180/270°의 두 게이지 값 → 결과.

- 큰 글씨, 64px 이상 버튼, 부호 선택, mm/0.01mm 눈금 칸 수 입력
- 기기 내 자동 저장, 이어서 측정, 같은 거리 재사용
- 연습 데이터는 실제 저장 기록과 분리
- 게이지 합계 불일치 시 계산 결과를 숨김
- 설치·로그인·외부 라이브러리·분석 추적 없음. 인터넷 연결 필요, 오프라인 지원 없음.
- 공개 소스에 사용자 사진이나 실제 설비 측정값은 포함하지 않음

## 배치와 계산

모터측 지지대의 U 게이지는 처음 위에서 고정측 허브를 측정합니다. 고정측 지지대의 L 게이지는 처음 아래에서 모터측 허브를 측정합니다. 측정봉이 눌리면 양수이고, 두 축을 함께 회전시킵니다. 게이지 접촉은 바깥둘레의 반경 방향입니다.

S=(U180−sU)/2, M=(L180−sL)/2, k=(M−S)/A.
앞발 증감=−(M+kB), 뒷발 증감=−(M+k(B+C)). 양수는 추가, 음수는 제거.

처짐값은 각 게이지의 실제 시작 위치부터 반 바퀴까지 별도 강체 시험에서 얻은 부호 있는 차이입니다. 상하 게이지의 처짐 부호가 다를 수 있습니다. 미보정은 명시하고, 이미 보정된 입력은 이중 보정하지 않습니다.

열팽창 목표는 0입니다. 수평 조정과 개별 발 들뜸은 범위 밖입니다. 상세 설명과 기술 출처는 `method.html`에 있습니다.

## 검증 및 개발

Node.js 22 이상, Python 3으로 다음을 실행합니다.

```text
npm test
npm run check
python -m http.server 4173 --bind 127.0.0.1
```

수학 테스트는 독립적인 축 높이 전진 모델, 평행/각도/반대 방향 보정, 부호 있는 처짐, SKF 수치 사례, 입력 오류를 포함합니다. 0.020 mm 합계 검사 기준은 설비 정렬 허용오차가 아닙니다.

## 배포

GitHub Pages: main 브랜치의 루트에서 게시합니다. 별도 빌드가 필요 없는 정적 사이트이며 모든 앱 자원은 상대경로입니다. 소스와 페이지는 공개됩니다.

선택적 WebMCP 읽기 도구는 지원하는 브라우저에서만 등록됩니다. 사용자 조작 없이 측정값을 바꾸지 않습니다.

문자 인코딩: UTF-8, BOM 없음. 확인 문자열: 한글 안전.
